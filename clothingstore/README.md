# Clothing Store — Project Documentation

This folder contains the project specification for building a MERN clothing e-commerce website.

## Documents
- `PRD.md` — product scope, users, requirements, workflows, acceptance criteria.
- `ARCHITECTURE.md` — application architecture, data model, API contracts, security and folder structure.
- `DESIGN.md` — visual direction, page layouts, responsive behavior and component guidance.
- `RULES.md` — strict implementation rules and constraints for the coding agent.
- `BUILD_PLAN.md` — phased implementation sequence and verification checklist.
- `ANTIGRAVITY_PROMPT.md` — starting prompt to give Antigravity.

## Non-negotiable stack
React, CSS, Node.js, Express, MongoDB, Mongoose, bcryptjs and JWT. Use only the application's own backend REST API. No external APIs or hosted services are required.

## How to use
1. Put this folder in the root of your project repository.
2. Open the repository in Antigravity.
3. Give it `ANTIGRAVITY_PROMPT.md` as the initial instruction.
4. Ask it to implement one phase at a time from `BUILD_PLAN.md`.
5. Review each phase and run the verification checklist before proceeding.

The documents define a deliberately small first version. Do not add features outside this scope without explicit approval.
